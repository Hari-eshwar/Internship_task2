# Advanced CSS3 & Responsive Architecture

A dependency-free responsive portfolio demonstrating CSS Grid, Flexbox, mobile-first media queries, CSS custom properties, accessible navigation, and persistent light/dark mode.

## Run
Open `index.html` directly in a modern browser. No build step or server is required.

## Highlights
- CSS Grid for the editorial work layout and responsive two-column sections.
- Flexbox for navigation, action groups, proof points, and footer alignment.
- Theme tokens in `:root`, with `.dark` overrides and `localStorage` persistence.
- Skip link, semantic landmarks, keyboard-friendly controls, responsive menu, and focusable links.
